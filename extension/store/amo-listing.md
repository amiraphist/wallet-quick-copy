# Firefox Add-ons listing copy

## Name

QuickCopy Wallet Control

## Summary

Copy a saved public Ethereum or Solana address into an X reply draft without auto-posting.

## Description

QuickCopy Wallet Control keeps up to ten labelled public Ethereum and Solana addresses ready while you use X on the web. When a relevant post asks for a wallet address, QuickCopy opens a compact picker. Selecting an address copies it and places it into the reply composer. You review the reply and press the final Post button yourself.

QuickCopy stores its wallet labels, public addresses, order, and appearance preferences locally in the browser. It never asks for seed phrases, private keys, recovery phrases, signing credentials, or passwords.
