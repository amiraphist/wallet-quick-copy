# Firefox Add-ons listing copy

## Name

QuickCopy Wallet Control

## Summary

Local-only public Ethereum and Solana address picker for direct X replies. It copies or inserts a selected address into a draft but never posts.

## Description

QuickCopy Wallet Control is a local browser helper for people who keep labelled public Ethereum and Solana addresses for direct replies on X. It runs only on `x.com` and `twitter.com`. When a post contains an explicit request for a compatible public address—for example, “Drop your SOL address” or “Comment your wallet”—QuickCopy adds its own clearly branded control beside that post.

The control opens a list of addresses that the user has already saved in the extension. A user must deliberately select one address. That action copies the selected public address and can place it in the X reply draft. QuickCopy never clicks, triggers, or submits X’s final Post action; the user reviews the draft and posts manually.

QuickCopy stores wallet labels, public addresses, display order, and appearance preferences only in local browser extension storage. It does not send data to a server, use analytics, load remote code, connect to a wallet, request transaction approval, or collect browsing history. It never asks for seed phrases, recovery phrases, private keys, passwords, signing credentials, or login details.

QuickCopy is an independent utility and is not affiliated with, endorsed by, or connected to X, Twitter, Ethereum, Solana, or any wallet provider.
