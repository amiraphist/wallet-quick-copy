# Chrome Web Store listing copy

## Name

QuickCopy Wallet Control

## Short description

Copy a saved public Ethereum or Solana address into an X reply draft without auto-posting.

## Detailed description

QuickCopy Wallet Control keeps public Ethereum and Solana addresses ready for wallet-request posts on X. Choose one address from a compact picker, copy it, and place it into the reply composer. The final Post action always remains manual.

QuickCopy stores labels, public addresses, display order, and trigger appearance preferences locally in the browser. It does not request, store, or transmit seed phrases, private keys, recovery phrases, signing credentials, or passwords.

## Single purpose declaration

The extension’s single purpose is to help users select and copy a saved public Ethereum or Solana address into an X reply draft.

## Privacy declaration

QuickCopy does not collect or transmit personal data. Saved labels and public wallet addresses remain in local browser storage. The extension uses clipboard access only after a user selects a wallet. It uses X/Twitter host access only to show the address picker and insert the user-selected public address into a reply draft.
