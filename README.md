# QuickCopy

QuickCopy is a local-first wallet-address helper for X/Twitter. It stores only public addresses, lets users choose a saved address, opens the reply composer, inserts that address, and leaves the final Post action entirely manual.

## Platform compatibility

| Platform | Current status | Notes |
|---|---|---|
| Windows | Supported | Install the Firefox extension package and use X in Firefox. |
| macOS | Supported | The same Firefox extension package works in Firefox on macOS. |
| Android | Preparation needed | Firefox for Android support depends on signed add-on distribution; the native X app cannot be modified by a browser extension. |
| iPhone/iPad | Separate target needed | A Safari Web Extension wrapper is required; the native X app cannot be modified by a browser extension. |

## Safety

QuickCopy must never store seed phrases, private keys, or signing credentials. It only copies and inserts public wallet addresses. The user always manually sends the reply.

## GitHub release

The project is intentionally not pushed to GitHub until the owner gives explicit final approval.
